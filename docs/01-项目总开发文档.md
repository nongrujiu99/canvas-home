# AI 无限画布网站 — 项目总开发文档

## 1. 项目目标

基于现有无限画布，开发一个完整可上线的网站产品。

第一阶段不重做 Canvas，只补齐：

- 官网首页
- 注册 / 登录 / 退出
- Dashboard
- 项目管理
- Canvas 项目化
- 自动保存
- 数据库
- 文件存储
- 后端 API
- 权限控制
- Vercel 上线
- 自定义域名

最终用户流程：

```text
官网
↓
注册 / 登录
↓
Dashboard
↓
新建项目
↓
进入 Canvas
↓
创作
↓
自动保存
↓
退出
↓
重新登录
↓
恢复项目
```

## 8. 核心原则

1. 不重做现有 Canvas。
2. 不提前引入复杂架构。
3. 第一版优先保证稳定和可上线。
4. 用户数据必须隔离。
5. Secret Key 不允许进入前端。
6. 文件不要 Base64 存数据库。
7. 自动保存必须 debounce。
8. 所有异步操作必须有 Loading / Error 状态。
