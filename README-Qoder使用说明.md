# AI 无限画布 — Qoder 完整开发包

## 目录
- `AGENTS.md`：项目总规则
- `.qoder/rules/`：Qoder 项目规则
- `docs/01~10`：完整开发规格和执行步骤

## 使用
1. 解压 ZIP。
2. 把 `AGENTS.md`、`.qoder/`、`docs/` 复制到真实代码仓库根目录。
3. 用 Qoder 打开整个仓库根目录，不要只打开 Canvas 子目录。
4. 第一次执行 `docs/10-Qoder开发执行指令.md` 的“只分析，不改代码”。
5. 确认 Qoder 理解现有 Canvas 后，再逐阶段开发。
6. 每个稳定阶段建议 Git Commit。

## 仓库更新
Qoder 以当前本地仓库为准。GitHub 有更新时先 `git pull`，再继续开发即可。开发包无需重复导入，除非项目规则或产品规格发生变化。
